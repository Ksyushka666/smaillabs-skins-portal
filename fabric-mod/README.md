# SmailLabs Skin Profiles — Fabric

Автор: **YTSmailDog**  
Команда: **SmailLabs**  
Сайт: https://smaillabs.onrender.com/

## Экран профиля

Нажмите **P** в клиенте Minecraft, чтобы открыть экран профиля.

В экран входят:

- имя локального профиля;
- выбор PNG-скина из файла;
- выбор PNG-плаща из файла;
- загрузка скина по HTTPS-ссылке;
- загрузка плаща по HTTPS-ссылке;
- выбор модели `classic` или `slim`;
- сохранение профиля в `config/smaillabs/profile.json`;
- локальный кэш файлов в `config/smaillabs/assets/`;
- ограничение загрузки 5 МБ и проверка PNG signature.

Токены сайта и пароли в моде не сохраняются. Следующим этапом можно добавить авторизованную синхронизацию с профилем SmailLabs и применение текстур к игроку через client renderer.

## Сборка

```bash
./gradlew build
```

Текущий модуль собирается для Minecraft **1.21.1**. Для 1.20.1 и 1.21.4 нужно создать version-specific Loom-модули с соответствующими Yarn mappings и оставить общий код профиля/загрузки без изменений.
